What you're seeing. The chat pane is React-style; the dark pane shows the exact SSE event stream the FastAPI backend will emit. Each metadata event carries a kind ∈ {text, crisis, journal, mood-update, breathing} — the frontend picks the matching React component via a switch. No LLM picks the UI; the orchestrator does, deterministically. Press ▶ Crisis path to see metadata.crisis_level=3 short-circuit the LLM and emit a structured card payload.
