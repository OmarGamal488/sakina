Point 4 — Monitoring Metrics 10 pts

File: api/app/telemetry.py — 5 OpenTelemetry instruments covering the 3 required categories.

Metric NameTypeCategoryWhat it monitors
sakina.chat.requestsCounter (by intent)Model / NLPIntent distribution — detects model drift if the pattern shifts unexpectedly
sakina.chat.latencyHistogram (ms)Model / NLPEnd-to-end response latency — catches slowdowns in RAG or LLM generation
sakina.message.lengthHistogram (chars)DataInput size distribution — very short = possible bot traffic; very long = edge cases
sakina.feedback.votesCounter (up / down)DataHelpfulness ratio — direct user signal on response quality over time
sakina.http.errorsCounter (by status code)ServerError rate — 4xx/5xx spikes indicate broken clients or backend failures

HF Space env vars for monitoring (Secrets tab)

  • AXIOM_TOKEN — bearer token for Axiom API
  • AXIOM_DATASET — dataset name (e.g. sakina)

When both are set, the API exports directly to Axiom via OTLP HTTP — no collector needed on HF Space.

Local stack
